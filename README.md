# 看護目標メーカー

学校生活で使える短い看護目標を、分野から選んでコピーできる静的Webサイトです。

## 使い方

1. 分野を選ぶ
2. 表示された目標を選ぶ
3. 「コピーする」を押す

目標データは [`data/goals.json`](data/goals.json) に分離されています。カテゴリーや目標を追加・編集すると、画面へ自動的に反映されます。

## ローカルでの確認

`fetch` でJSONを読み込むため、`index.html` を直接開かず、リポジトリのルートでローカルサーバーを起動してください。

```bash
python3 -m http.server 8000
```

起動後、<http://localhost:8000> を開きます。GitHub Pagesでもそのまま動作します。
