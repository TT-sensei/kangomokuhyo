# 看護目標メーカー

学校生活で使える短い看護目標を、分野から選んで使える静的Webツールです。

## できること

- 学校生活の分野から目標を選ぶ
- 複数の目標を選択して一覧にまとめる
- 選んだ目標をまとめてコピーする
- 分野を切り替えても、選んだ目標を保持する
- 目標データをJSONで管理し、あとから簡単に追加・編集する

## 使い方

1. 左側から分野を選びます。
2. 中央に表示された目標から、使いたいものを選びます。
3. 右側の「選んだ目標」で内容を確認します。
4. 「コピーする」でまとめてコピーできます。

## 目標データについて

目標の一覧は `data/goals.json` に分離して管理しています。

画面のHTMLやJavaScriptを変更しなくても、`goals.json` にカテゴリーや目標を追加することで、表示内容を増やせます。

今後、目標数を増やしたり、検索・お気に入り・ランダム表示・タグなどの機能を追加したりしやすい構成になっています。

## 構成

```text
kangomokuhyo/
├── index.html
├── style.css
├── script.js
├── data/
│   └── goals.json
└── README.md
```

## 技術構成

- HTML / CSS / JavaScript
- JSONによる目標データ管理
- サーバーやデータベースを必要としない静的Webサイト
- GitHub Pagesで公開可能

## 開発時の確認

目標データをJSONから読み込むため、開発時に `index.html` を直接開くのではなく、ローカルサーバーを利用すると確認しやすくなります。

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開いて確認できます。

これは開発用のローカル環境であり、公開サイトのURLではありません。

## データを追加する

`data/goals.json` を編集し、既存の形式に合わせてカテゴリーや目標を追加してください。

目標は、学校生活でそのまま使いやすいように、短く、前向きで、具体的な表現にすると扱いやすくなります。
