# 看護目標メーカー

学校全体で使える「看護目標」を、分野から選んで組み合わせるための静的Webツールです。

学校生活のさまざまな場面に合った目標文を探し、必要なものを選んでまとめてコピーできます。

## できること

- 学校生活の分野から目標を選ぶ
- 目標を複数選択して一覧にまとめる
- 分野を切り替えても、選んだ目標を保持する
- 選んだ目標を個別に外す
- 選んだ目標をすべて解除する
- 選んだ目標をまとめてコピーする
- 目標をキーワードで検索する
- 目標データをJSONで管理し、あとから追加・編集する

## 使い方

1. 左側から分野を選びます。
2. 中央に表示された目標から、使いたいものを選びます。
3. 選んだ目標は右側の一覧に追加されます。
4. 必要に応じて、別の分野からも目標を選びます。
5. 右側の「まとめてコピー」で、選んだ目標を一度にコピーできます。

特定の言葉から探したい場合は、「目標を検索」を使います。

## 目標データについて

目標の一覧は `data/goals.json` に分離して管理しています。

画面のHTMLやJavaScriptを変更しなくても、既存の形式に合わせてカテゴリーや目標を追加することで、表示内容を増やせます。

目標数が増えても管理しやすいよう、データと画面の処理を分離した構成にしています。

## 構成

```text
kangomokuhyo/
├── index.html
├── style.css
├── script.js
├── data/
│   └── goals.json
└── README.md
```

## 技術構成

- HTML / CSS / JavaScript
- JSONによる目標データ管理
- サーバーやデータベースを必要としない静的Webサイト
- GitHub Pagesで公開可能

## データを追加する

`data/goals.json` を編集し、既存の形式に合わせてカテゴリーや目標を追加してください。

目標は、学校生活でそのまま使いやすいように、短く、前向きで、具体的な表現にすると扱いやすくなります。

## 開発について

このサイトはGitHub Pagesで公開できる静的Webサイトです。

目標データをJSONから読み込むため、ローカルで動作確認する場合は、Pythonなどの簡易ローカルサーバーを利用できます。

```bash
python3 -m http.server 8000
```

その場合はブラウザで `http://localhost:8000` を開きます。

`localhost` は開発時の確認用URLであり、公開サイトのURLではありません。
